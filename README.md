# 🎬 Movie Seat Booking App

A movie seat booking web application built using HTML, CSS, and JavaScript. Users can select a movie, choose their preferred seats, and view the total ticket price dynamically.

## 🚀 Features

- **Movie Selection:** Choose a movie from the available options.
- **Dynamic Ticket Pricing:** Ticket price updates based on the selected movie.
- **Interactive Seat Selection:** Select and deselect available seats.
- **Booking Summary:** View the number of selected seats and the total ticket price.
- **Real-Time Updates:** Booking information updates dynamically when seats or movies change.
- **Responsive Interface:** Simple and user-friendly interface for interacting with the booking system.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Event Handling
